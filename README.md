## MediBook — Hospital Appointment System

Full-stack MERN app for patient self-service booking.
Patients register, browse doctors by specialization,
and book/cancel appointments.

**Tech:** MongoDB · Express.js · React.js · Node.js · JWT · REST API

**Key features:**
- Role-based access control (Patient / Doctor / Admin)
- Time-slot validation preventing double-booking
- 97% API success rate across 50+ Postman test scenarios



## Setup
git clone https://github.com/sabiya-sachdeva/MediBook
cd MediBook && npm install
npm run dev
